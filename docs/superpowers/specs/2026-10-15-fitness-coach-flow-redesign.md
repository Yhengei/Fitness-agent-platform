# 健身管家分步工作流设计

## 目标

把当前长页面改为清晰的三步工作流，减少信息拥挤并提升训练建议、每日建议和自主学习结果的可读性。

## 三个视图

1. **今日记录**：填写训练状态、实际动作和个人限制。提交后自动跳转到 Agent 分析。
2. **Agent 分析**：以独立页面展示八个角色的实时进度和一句话结论，结构化证据作为折叠详情。运行完成后自动进入总结。
3. **今日总结**：突出最终训练计划、每日建议、学习 Agent 提案和周报指标；可返回分析或今日记录。

视图使用 URL hash（`#today`、`#agents`、`#report`），刷新后保持可分享且不引入新的路由依赖。

## 视觉与文案

- 移除 `FORM` 品牌和英文品牌副标题，统一使用“专属于你的健身管家”和“多 Agent 协作平台”。
- 页面采用暖白、深墨绿和珊瑚风险色；用运动轨迹线、编号节点和轻量装饰线增强健身场景感。
- 结果标题、每日建议和 Learning Agent 使用大字号、强对比色和独立背景，避免重要信息被小字淹没。
- Agent 结论正文至少使用 14px 视觉层级，证据 JSON 继续折叠。

## 行为约束

- 不改现有 API、SSE 事件协议、数据库或 Docker 配置。
- 提交记录后自动跳到 Agent 视图；完成/失败后自动跳到总结视图或显示错误状态。
- 左侧步骤、页面顶部步骤条和返回按钮均可切换视图。
- 移动端按当前步骤单列显示，保持输入、分析、总结的顺序。
